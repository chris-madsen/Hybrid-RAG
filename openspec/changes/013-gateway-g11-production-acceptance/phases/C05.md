## Objective
**Observable behavior:** a proposed fallback provider/model or residency target cannot inherit the primary route's authorization, body digest or receipt; each permitted destination gets fresh authorization and each denied destination receives zero sends.
**Non-goals:** no automatic provider selection, no fallback destination chosen by this plan, no bypass of Gateway, no new proxy or public DTO without G02.
**Definition of accepted:** deterministic destination/data-class/policy matrix proves fresh authorization and zero-send denials at the selected actual dispatch boundary.

- Security/identity: fresh provider/model/data-class/body digest/policy version, unique attempt identity and explicit opt-in per destination.
- Provenance: primary and fallback config pins, policy result IDs, zero/non-zero mock sends and final request hashes.
- Accepted ADR/OpenSpec: ADR-007, ADR-017, ADR-019; G11-010/011/012.

- Planned removal: remove only the currently unconditional fallback rejection if a reviewed, complete per-destination authorization replaces it; no temporary bypass.
- Rollback: restore fallback-deny behavior and keep destination uncertified.
