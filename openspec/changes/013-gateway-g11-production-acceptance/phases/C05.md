## Objective

**Observable behavior:** A selected native non-streaming Responses route is certified only after controlled after-hook capture and explicitly authorized real provider acknowledgement on exactly the final outbound bytes.

**Non-goals:** no new ACE proxy/agent scheduler, model-invoked context tool, Chat fallback, direct provider credential bypass, token gate or silent fake completion.

**Definition of accepted:** every owned scenario below passes its cheapest deterministic tests and its specified external evidence gate; independent G02 decision and required egress are observed, not inferred from structural tests.

- **invariant:** No false final-wire success from a PreLLM receipt, synthetic server or later-mutated bytes.
- **frame:** all original Responses input items, function-call IDs, reasoning/opaque fields and current protected data remain unchanged except the approved additive context or an explicitly versioned outcome; other ACE contexts/accepted historical v1 schema are untouched.
- **exceptional:** every policy, provider, freshness, audit, timeout, source SHA and replay failure produces typed BLOCKED, UNKNOWN or PARTIAL as applicable, with zero unauthorized new provider sends; rescue never converts to Chat.

## Architecture contract

- Owning bounded context: Bifröst request observation and ACE evidence ledger.
- Event Storming: Hermes submits request/tool result; ACE prepares verified evidence; Bifröst proposes a network send; policy accepts or denies; provider may complete/fail/incomplete; Harbor observes task outcome. This phase owns only its indicated part, not a new event bus.
- Proposed immutable `State | Command | DomainError` contract: use read-only input/receipt/attempt ADTs and pure `decide`/`validate` functions at the domain boundary; Event only as an observed fact, no mandatory OO aggregate. FSM state transitions apply to single-use send permits, N/A for stateless projection.
- Application/ports: existing TypeScript Effect policy, audit and context-transform services; real cancellation and idempotency at the adapter boundary. No duplicated provider credential storage.
- Adapters/provider: existing thin Go Bifröst plugin and versioned authenticated ACE local HTTP; Bifröst native Responses provider route is **not yet certified**.
- Security/identity: No false final-wire success from a PreLLM receipt, synthetic server or later-mutated bytes.
- Source provenance: pin exact original/projected body digests, provider/model, agent-visible session correlation (not authentication), source SHA and provider-wire evidence class.
- ADR/OpenSpec: ADR-007/009/017/019, accepted change 010 as historical behavior boundary, change 013 G11 and native Responses specs, change 002 Harbor.
- Reuse: Bifröst native schemas/streaming, existing TS/Effect Gateway and TypeSpec compiler, existing Harbor; inspect exact maintained implementations instead of building a replacement.
- Removal: retire only superseded executable Chat paths after safe expand-contract and equivalent tests; historical v1 contract source remains preserved until formal retirement.
- Rollback/STOP: Invalidate route certificate, disable provider generation and retain final wire mismatch evidence. No real provider send without C03/C04 G02 and explicit egress authorization; do not use a fake upstream as substitute.
- Phase integration: downstream phases consume immutable verified outcomes, **never** treat `PREPARED` as a permit or replace a missing upstream gate with optimistic fixtures.

## Task steps

1. Freeze exact ACE source commit, pinned Bifröst commit, plugin order/config, model/provider and policy before attempting a trial.
2. RED mock: late plugin mutates model/tool/reasoning or removes an ACE context item after PreLLM; final-send verifier must detect and deny.
3. RED evidence: mock provider success may be MOCK_WIRE_VERIFIED, never REAL_PROVIDER_WIRE_VERIFIED; stale SHA or changed plugin config invalidates approval.
4. Instrument the existing real-projection/provide-evidence scripts at the actual send seam, with redacted hashes and a correlated downstream ack; do not write raw private source into public artifacts.
5. GREEN controlled synthetic upstream: exact native input/tool/protected request equivalence and zero-send for unverified mutator ordering.
6. With separate explicit provider/model/data/egress consent, run a disposable synthetic PUBLIC provider request; verify final pre-TLS content and real provider response at the same attempt identity.
7. Record protocol/provider/model/source SHA/semantic mode and failures separately. No streaming or agent-level certification is inferred.
8. On any mismatch, set route not_certified and rollback to BLOCK before further provider traffic.

9. Run four independent BUILD/ARCHITECTURE/SECURITY/PLAN COVERAGE reviews, record effective source/binary SHA and exact CI checkout; block if required approvals or live evidence are absent.
10. Commit a focused change on a branch based on the latest `main`, open a direct-to-main PR, and re-run the canonical phase checker against current design/specs. No unsupervised merge.
