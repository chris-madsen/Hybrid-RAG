## Objective
**Observable behavior:** a Bifröst inner retry callback cannot dispatch under an old projection receipt. Every actual callback has fresh authorization for the exact destination/body/policy, or all inner retry/extra-attempt paths are proven and enforced disabled for the certified route.
**Non-goals:** no second proxy, no local recreation of Bifröst retry scheduling, no guessed attempt ordinal contract, no provider egress.
**Definition of accepted:** G02 selects a feasible option; deterministic mock tests force transient failure, per-key extra attempt, encrypted-reasoning mutation, replay, cancellation and concurrent/restart conditions as applicable; each permitted dispatch is independently bound or no second callback can send.

## Requirements and invariants
| ID | Require / precondition | Ensure / postcondition | Invariant and frame | Exceptional outcome |
|---|---|---|---|---|
| G11-009 | Exact pinned Bifröst callback boundary and approved decision; retry condition is deterministic. | A second same-provider send receives a distinct fresh decision bound to the final body/destination, or cannot occur. | An ingress APPLY/PreLLM receipt never authorizes an unobserved retry. | No observed dispatch seam/config guarantee means the route remains `not_certified`. |
| G11-011 | Request/session/body/destination identities and one-use semantics are defined. | Reused, stale, mismatched, concurrent or restarted attempts deny before a send. | No replay or race can consume one decision twice; user worktree and original request bytes remain unchanged. | Unknown persistence/CAS semantics remain blocked; never infer a successful denial from an error. |
| G11-012 | Current policy, audit and deadline are available at the selected boundary. | Timeout, NOT_READY, secret or audit failure yields a typed no-send result. | Failure is not absence, empty success or a pass-through. | Any uncertain authorization blocks the callback and keeps evidence partial/unknown. |

**Frame conditions:** no change to accepted Gateway route, no private data, no upstream Bifröst edit without a separate approved upstream change, no new service/store by default.

## Architecture contract
- Owning bounded context: existing Gateway Projection domain/application; Bifröst remains provider-dispatch owner.
- Application service and ports: if G02 accepts a per-send port, keep policy orchestration in TypeScript + Effect; Go remains serialization/transport adapter.
- Adapters/provider: pinned Bifröst `executeRequestWithRetries` remains the behavioral oracle; use its exact official extension point if one is owner-approved.
- Runtime composition: current `PreLLMHook` runs in outer `tryRequest`; `executeRequestWithRetries` invokes callbacks below it. A static receipt marker in `plugin/main.go` cannot solve this alone.
- Security/identity: fresh destination/body digest, data class, policy version, deadline and single-use attempt identity at the actual callback.
- Provenance: pinned Bifröst SHA, effective `NetworkConfig`, exact plugin order, callback count, provider-mock send count and final body digests.
- Accepted ADR/OpenSpec: ADR-007, ADR-012, ADR-017, ADR-019; G11-009/011/012.
- Existing implementation to reuse: official Bifröst retry worker and existing ACE `GatewayProjectionService`; no retry scheduler, proxy or new framework.
- Planned removal: delete any provisional outer-hook-only claim if G02 selects another boundary; keep fail-closed current guard until replacement proven.
- Rollback: disable/uncertify the retry route; never silently downgrade to an unapproved provider path.
