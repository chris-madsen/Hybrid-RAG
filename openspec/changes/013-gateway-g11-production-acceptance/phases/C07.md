## Objective
**Observable behavior:** one retrieval-demanding, nontrivial coding task is completed by the explicitly selected agent through the loaded Bifröst ACE plugin, authenticated ACE Projection and allowed provider, with independent task-quality checks and exact source/runtime/route identity.
**Non-goals:** no exclusive host-context/compaction claim, no hidden provider continuation, no second ACE agent-facing path, no task from private user source without consent.
**Definition of accepted:** end-to-end evidence binds agent/provider/model/runtime/plugin/source/attempt, demonstrates the actual provider response and independent accepted task result; all unsupported routes and bypasses remain ineligible.

## Architecture contract
- Owning bounded context: existing Agent Access Bifröst adapter + Gateway Projection; Evaluation reads evidence only.
- Application service and ports: existing TypeScript + Effect Gateway service; no retrieval in Go and no agent tool server.
- Adapters and provider: owner-selected Harbor agent adapter; exact pinned Bifröst plugin; ACE runtime bundle at the Bifröst host.
- Actual runtime composition: agent → configured Bifröst endpoint → authenticated loopback ACE Projection → approved provider. Direct Hermes `ContextEngine` and MCP/model tool delivery are prohibited.
- Security/identity: use a separately approved OAuth/credential route; never type or log credentials; no `OPENAI_API_KEY` inference.
- Provenance: exact task/source digests, agent build/version, model/reasoning, Bifröst/ACE plugin/runtime pins, projection/final-send IDs, response and verifier output.
- Accepted ADR/OpenSpec: ADR-007, ADR-009, ADR-012, ADR-017, ADR-019; G11-013–016.
- Existing implementation to reuse: `scripts/harbor_hermes_codex_oauth.py`, `src/domain/feedback-harbor-config.ts`, `scripts/feedback-loop-preflight.ts`, `scripts/real-provider-runtime.mjs`, `scripts/real-provider-process.mjs`; adapt only the configured route, not the agent runtime.

- Planned removal: never re-enable native ACE ContextEngine or model-invoked ACE tools; preserve legacy historical artifacts without treating them as current evidence.
