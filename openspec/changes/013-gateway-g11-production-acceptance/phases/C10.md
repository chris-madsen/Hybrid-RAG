## Objective
**Observable behavior:** a predeclared immutable main/holdout task split is run or its incomplete frontier is reported; each exact route/provider/model/source/config receives a separate truthful status and owner handoff.
**Non-goals:** no post-hoc task substitution, tuning on holdout, filtering failed trials, blanket route certification, automatic production approval or automatic fivefold claim.
**Definition of accepted:** frozen task identities and SHA bindings match all arms; raw trials and quality results reconcile; provider/send evidence is complete or gaps remain explicit; owner decides each route separately.
