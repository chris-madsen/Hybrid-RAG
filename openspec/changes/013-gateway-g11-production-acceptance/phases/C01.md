## Objective

**Observable behavior:** Only native Responses ingress and the authenticated Gateway v2 projection contract are recognized. All other generation routes and every uncertified provider dispatch receive explicit denial with zero external provider sends. TypeSpec v2 is the only active generated projection contract; prior projection schemas, runtime adapters, generated DTOs, compatibility tests and historical reports in scope are removed.

**Non-goals:** no new ACE proxy/agent scheduler, model-invoked context tool, protocol fallback, direct provider credential bypass, token gate or silent fake completion.

**Definition of accepted:** the explicit C01 owner decision is recorded, every owned deterministic positive/negative oracle passes, all previous projection owners/artifacts in scope are removed, and provider dispatch remains blocked. No external egress evidence is required or authorized in C01.

## Architecture contract

- Owning bounded context: Gateway transport and the public contract boundary.
- Event Storming: Hermes submits request/tool result; ACE prepares verified evidence; Bifröst proposes a network send; policy accepts or denies; provider may complete/fail/incomplete; Harbor observes task outcome. This phase owns only its indicated part, not a new event bus.
- Proposed immutable `State | Command | DomainError` contract: use read-only input/receipt/attempt ADTs and pure `decide`/`validate` functions at the domain boundary; Event only as an observed fact, no mandatory OO aggregate. FSM state transitions apply to single-use send permits, N/A for stateless projection.
- Application/ports: existing TypeScript Effect policy, audit and context-transform services; real cancellation and idempotency at the adapter boundary. No duplicated provider credential storage.
- Adapters/provider: existing thin Go Bifröst plugin and versioned authenticated ACE local HTTP; Bifröst native Responses provider route is **not yet certified**.
- **Security/identity:** all unsupported routes and uncertified provider generation remain fail-closed; a prepared v2 body is never an egress authorization.
- Source provenance: pin exact original/projected body digests, provider/model, agent-visible session correlation (not authentication), source SHA and provider-wire evidence class.
- **ADR/OpenSpec:** ADR-007/009/017/019/020, change 013 G11 and native Responses specs, change 002 Harbor.
- Reuse: Bifröst native schemas/streaming, existing TS/Effect Gateway and TypeSpec compiler, existing Harbor; inspect exact maintained implementations instead of building a replacement.
- **Removal:** delete every superseded projection implementation, schema, generated DTO, fixture and approved historical report; TypeSpec v2 is the only active contract source.
- **Rollback/STOP:** Keep every generation path BLOCKED/not_certified; never restore a retired protocol. The owner approved C01's contract/removal design on 2026-11-18; provider egress and later phases remain separately gated.
- Phase integration: downstream phases consume immutable verified outcomes, **never** treat `PREPARED` as a permit or replace a missing upstream gate with optimistic fixtures.
