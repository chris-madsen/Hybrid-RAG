## Objective
**Observable behavior:** a supported `stream=true` request preserves ACE projection, route, tools, original message semantics and opaque fields; ordered response chunks, terminal result, cancellation, partial delivery and usage availability are reported honestly.
**Non-goals:** no custom SSE proxy/parser, no stream-to-nonstream downgrade, no private chunk logging, no real provider call in this planning stage.
**Definition of accepted:** deterministic pinned-Bifröst stream fixture proves success, cancellation-before-send, cancellation-after-bytes, truncation and missing usage separately; real provider stream is a distinct later gate.

## Architecture contract
- Owning bounded context: Gateway Projection; existing Evaluation domain owns usage/outcome status.
- Application service and ports: preserve existing Effect request authorization and cancellation boundary; no new mutable domain service.
- Adapters and provider: use the pinned Bifröst `HTTPTransportStreamChunkHook`/official stream pipeline at `core/schemas/plugin.go:359-390`; do not implement a second HTTP/SSE stack.
- Actual runtime composition: exact Bifröst stream route → same ACE projection plugin → official stream callback → existing agent/provider result path.
- Security/identity: same explicit provider/model/policy as non-stream; stream cancellation cannot authorize retries implicitly.
- Provenance: ACE/Bifröst/plugin/config pins, request/attempt IDs, chunk sequence and terminal state; omit private chunk payloads.
- Accepted ADR/OpenSpec: ADR-006, ADR-007, ADR-012, ADR-017, ADR-019; G11-005–008.
- Existing implementation to reuse: pinned Bifröst stream hooks, existing `Effect` cancellation contract in `test/http-cancellation.contracts.test.ts`, existing `EvaluationSuite` unknown/partial semantics.
- Planned removal: none; no custom parser is introduced.
- Rollback: unsupported stream variants remain disabled; preserve the accepted non-stream route and `providerWire=not_certified` for streaming.
