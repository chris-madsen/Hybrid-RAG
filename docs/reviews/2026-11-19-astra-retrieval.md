## One query, from bytes to evidence

1. The entry point is `src/bin/ace-gateway-http.ts`, not a vector-search CLI. The composition root gathers the workspace manifest, selects real providers when enabled, builds the local index and publishes it before installing `makeContextTransformService` (`src/bin/ace-runtime.ts:641–715,840–874,990–1076,1103–1139`). Local-hash embeddings and `makeLocalContextProvider` are not the default production fallback. Jev's experimental route selector is not the gateway query planner. Rust's `BENCHMARK_COMPONENTS_ENABLED` is false. These are different from the real native ast-grep dependency.
2. Candidate identity includes workspace, path, content digest, symbol span and semantic anchor. Unsupported grammar, binary/invalid UTF-8, missing reads and digest races are recorded, not converted to clean absence (`src/adapters/local-code-index.ts:99–104,277–343,356–424`). Git status or non-Git size/mtime identifies *possible* changes; it does not attest source bytes. `node-workspace-port.ts:208–225,275–345,479–506` and `workspace-sync.ts` separate observation from publication. This defends against quoting a stale hit. It does **not** guarantee that every unselected dependency is found; verified precision and retrieval recall are different.
3. `qdrant-sdk-adapter.ts:97–147,186–205` is a policy and response-validation boundary around the official REST SDK, not a new network client. `http-provider-boundaries.ts:221–261` delegates dense/sparse filters and reciprocal rank fusion to Qdrant. `qdrant-context-provider.ts:746–865` checks membership before pruning; changed source and unchanged vectors may legitimately belong to one stable collection. Atomic Qdrant API operations alone cannot bind a model citation to bytes concurrently edited outside Qdrant. Keep the ACE source identity; do not implement RRF again. The older alias path is not proof that production's direct stable collection is fenced.
4. `qdrant-context-provider.ts:1109–1225,1261–1345,1553–1609` can reprioritize/rerank candidates, checks exact source and makes a final per-selected-path read; one scoped refresh/retry is possible. Multiple hits from one path share a read. This is valuable intentional duplicate I/O, unlike redundant decoding in the Go connector. `utf8-range.ts:34–70` distinguishes UTF-8 byte columns from LSP UTF-16 columns; the semantic same-name probe resolved the two definitions to different lines, not merely identical text. No tested assertion implied recall of symbols absent from candidate generation.
5. `context-transform-service.ts:77–82,140–149,162–191` forces code only, explicitly **disables docs, memory and history**, and rejects empty evidence. `ace-runtime.ts:1105–1114` passes an assembler without an exact model counter. The estimate is `ceil(text.length/4)` (`context-assembly.ts:67`); the native service supplies `Number.MAX_SAFE_INTEGER`, not a verified remaining model window. Original history removed by the projection itself: **none of the original native input items** (`responses-projection.ts:162–178`). The added item can avoid future tool reads, but neither a character estimate nor repeated-code suppression measures them. Do not introduce a guessed mandatory token cap.
